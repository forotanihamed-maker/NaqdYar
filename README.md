# نقدیار

دفتر چک و مطالبات برای کسب‌وکارها (نسخه اولیه، ساخته‌شده روی ساختار حساب‌کتاب).

## اجرا
npm install && npm run dev   (ساخت نسخه انتشار: npm run build · تست: npm test)

## ساختار
- src/domain/ledger.js : قوانین خالص (مانده، معوق، نرمال‌سازی داده، وضعیت وعده)
- src/hooks/useLedger.js : state و عملیات (ثبت، وضعیت چک، پرداخت، حذف، بازیابی)
- src/utils.js : تبدیل تاریخ شمسی (بدون Intl)، اعداد فارسی، نرمال‌سازی جست‌وجو، پشتیبان خراب
- src/file.js : نوشتن فایل پشتیبان/CSV (نقطه‌ی تعویض برای اشتراک‌گذاری اندروید)
- src/pages/ : نمای کلی، چک‌ها، بدهکاران/طلبکاران (یک کامپوننت با پارامتر dir)، پشتیبان
- src/components/ : فرم ثبت، ردیف سند، اجزای فرم، ErrorBoundary (بازیابی پس از خطا)
- src/styles.css : رنگ‌ها در بالای فایل (--brand برای رنگ برند)
- tests/ : تست‌های Node برای قوانین دامنه، تاریخ شمسی و CSV

## مدل داده
سند (item) = چک یا «حساب بدون چک»، با جهت in (دریافتی) یا out (پرداختی). چک وضعیت open/done/bounced دارد؛ حساب پرداخت مرحله‌ای دارد. مبالغ ریال و تاریخ‌ها به‌صورت میلادی ISO ذخیره و شمسی نمایش داده می‌شوند. داده فقط روی همین دستگاه و داخل برنامه ذخیره می‌شود؛ حذف برنامه یا پاک‌شدن اطلاعات آن داده را از بین می‌برد، پس از صفحه «پشتیبان» فایل بگیرید.

## رابط کاربری (UX)
- ناوبری گروه‌بندی‌شده؛ در موبایل نوار پایین با دکمه‌ی «+» و منوی «بیشتر». نشانگر تعداد موارد نیازمند اقدام روی منو.
- حذف و تغییر وضعیت بدون پنجره‌ی تأیید انجام می‌شود و در Toast گزینه‌ی «بازگردانی» دارد (hook: `notify(msg, undo)`).
- فرم‌ها: اعتبارسنجی درون‌خطی، Esc برای بستن، دکمه‌های همیشه‌پیدا، میان‌بر تاریخ (۳۰/۶۰/۹۰ روز)، «ثبت و سند بعدی».
- فونت به‌صورت محلی با `@fontsource/vazirmatn` بارگذاری می‌شود.
